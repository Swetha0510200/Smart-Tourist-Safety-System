# 🛡️ Smart Tourist Safety Monitoring and Emergency Response System

## 📌 Project Overview

The **Smart Tourist Safety Monitoring and Emergency Response System** is a Flask-based web application designed to enhance tourist safety through location monitoring, AI-assisted safety analysis, emergency support, and administrative monitoring.

The system helps tourists manage their safety information, monitor their current location, analyze safety conditions, and report incidents. An admin dashboard allows authorities to monitor tourist activities and safety-related information.

---

## 🎯 Objectives

- Improve tourist safety using intelligent monitoring.
- Provide location-based safety analysis.
- Maintain tourist digital identity information.
- Manage emergency contact details.
- Provide SOS and incident reporting support.
- Enable administrators to monitor tourist safety activities.

# ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Swetha0510200/Smart-Tourist-Safety-System.git
```

### 2. Navigate to Project Folder

```bash
cd Smart-Tourist-Safety-System
```

### 3. Install Dependencies

```bash
pip install flask requests
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

```
http://127.0.0.1:5000
```
